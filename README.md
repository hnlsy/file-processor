# 📁 File Processor - 批量文件处理工具

支持 Excel、PDF、图片的批量自动化处理。

## ✨ 功能特性

- **Excel**: 批量读取、多 Sheet 合并、数据清洗导出
- **PDF**: 文本提取、多文件合并、页面裁剪
- **图片**: 批量压缩、格式转换、尺寸调整
- 支持定时调度自动执行

## 🚀 快速开始

```bash
pip install -r requirements.txt
python main.py --help
```

## 📦 技术栈

- Python 3.10+
- openpyxl（Excel）
- pypdf（PDF）
- Pillow（图片）
